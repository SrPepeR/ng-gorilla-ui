Theming

ngx-gorilla-ui ships a light and a dark theme built on CSS custom properties. Colors use light-dark(), so the theme follows color-scheme: the system preference by default, or a fixed choice set by GorillaTheme.

1. Load the tokens

Add tokens.css to the styles of your application in angular.json, before your own global styles. 

{{ stylesSnippet }}

2. Provide the theme

provideGorillaTheme() applies the theme as soon as the app starts. The default theme is system, which follows prefers-color-scheme and its changes; the user's choice is stored in localStorage. On the server nothing is read nor stored. 

{{ providerSnippet }}

3. Let the user choose

GorillaTheme exposes the chosen mode (theme), the applied one (resolvedTheme) and setTheme(). This page is using {{ theme.theme() }}, resolved to {{ theme.resolvedTheme() }}. 

{{ serviceSnippet }}

4. Override any token

The tokens live in the gorilla cascade layer with :where() selectors, so any rule of your app wins without !important, for the whole app or for a part of it. Every public token is listed on the Tokens page. 

{{ overrideSnippet }}

User preferences

  • Reduced motion: every --gorilla-duration-* token becomes 0s.
  • Reduced transparency: translucent layers such as the scrim become nearly opaque.
  • More contrast: muted text and borders switch to their strongest step.
  • Forced colors: surfaces, text, borders and focus use the system colors.
