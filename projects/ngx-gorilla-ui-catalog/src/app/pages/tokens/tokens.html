Tokens

Every value of ngx-gorilla-ui is a CSS custom property with the --gorilla- prefix. Components only read the semantic tokens; the palettes are the raw material they are built from. Switch the theme in the header to see both versions.

Color roles

The color input of the components picks one of these roles. Each pair of background and text passes WCAG AA (4.5:1) in both themes; the ratios below are measured live. Each role <role> exposes --gorilla-<role>-solid, -solid-hover, -solid-active, -on-solid, -subtle, -subtle-hover, -on-subtle and -border.

Palettes

Twelve steps per tone: 1-2 backgrounds, 3-5 subtle backgrounds, 6-8 borders, 9 the solid color (the same in both themes), 10 its hover, 11 low-contrast text and 12 high-contrast text. Each tone also has -active (the pressed solid) and -contrast (the text on the solid).

@for (tone of tones; track tone) {
{{ tone }}
    @for (step of steps; track step) {
  1. --gorilla-{{ tone }}-{{ step }}
    2. }
}
