Button

gorilla-button goes on the native <button> or <a> element, with no wrapper, so the element keeps its own semantics, keyboard behavior and attributes. Switch the theme in the header to see both versions, and use Tab to see the focus ring.

Disabled

disabled sets the native attribute on <button>. On <a> it sets aria-disabled="true" and tabindex="-1" and blocks the navigation. In both cases no click handler runs.

Accessibility

  • It is the native element, so it keeps its role, its keyboard behavior (Enter and Space on buttons, Enter on links) and every attribute you set.
  • Give icon-only buttons an aria-label, and type="button" to buttons inside a form that do not submit it.
  • A disabled <a> gets aria-disabled="true" and tabindex="-1"; your own values of those attributes come back when it is enabled.
  • The focus ring only shows on keyboard focus (:focus-visible).
  • Every color pair passes WCAG AA in both themes. With prefers-reduced-motion: reduce the transitions and the hover and press scale are immediate, and with forced-colors: active the system colors draw the button.
