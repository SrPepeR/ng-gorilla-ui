Button

gorilla-button goes on the native <button> or <a> element, with no wrapper, so the element keeps its own semantics, keyboard behavior and attributes. Switch the theme in the header to see both versions, and use Tab to see the focus ring.

Disabled

disabled sets the native attribute on <button>. On <a> it sets aria-disabled="true" and tabindex="-1" and blocks the navigation. In both cases no click handler runs.
